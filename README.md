## 🔥 Featured Projects

### 🌍 [Unmapped](https://github.com/avikagupta03) — Solo Full-Stack Project
`Next.js 14` `Node.js` `Express` `MongoDB Atlas` `JWT`
- Full-stack travel platform with 22 curated trips/treks, live search, filters, and JWT-based auth with user profiles & booking history
- Booking pipeline with Nodemailer confirmation emails, node-cron re-engagement jobs, and WhatsApp pre-filled messaging on booking success
- Admin dashboard with full CRUD for trips/treks, inquiry status tracking, admin notes, and WhatsApp links per inquirer

### 🤖 CORE — Multi-Agent RFP Orchestration Platform
`Python` `FastAPI` `Flask` `Gemini` `Supabase` `React`
- Multi-agent AI system using Google Gemini + FastAPI with a 4-agent pipeline: requirement extraction, SKU matching, pricing, and proposal assembly
- LLM-driven agent routing where Gemini dynamically decides the next agent, with a human-in-the-loop approval step
- Google OAuth with per-user RFP isolation and a real-time React + Recharts analytics dashboard, backed by Supabase (Postgres) with automatic SQLite fallback

### 🧬 MultiCybGAT — Research Project
`Graph Attention Networks` `NLP` `NLTK`
- Cyberbullying detection model using a GAT architecture with NLP preprocessing, tokenization, and feature extraction
- Trained & evaluated on 9 multilingual datasets, achieving a 14.8% improvement over baseline models (accuracy, F1-score)
- Co-authored research paper currently under peer review
